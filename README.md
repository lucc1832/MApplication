## 功能与下载速查

Android Java 基础模板工程：MainActivity 加载主布局，用于界面与开发练习；当前未见独立业务功能，需源码构建。

### 下载到另一台电脑

- [下载源码 ZIP](https://github.com/lucc1832/MApplication/archive/refs/heads/master.zip)，或在仓库页面选择 **Code → Download ZIP**。
- 使用 GitHub CLI：`gh repo clone lucc1832/MApplication`。
- 整理时未发现本仓库 Releases 的安装包附件；上述 ZIP 是源码/资料，不是现成安装包。原说明中的其他下载入口见下文。

### 使用与迁移

使用 Android Studio 导入并构建。当前 MainActivity 仅加载布局，不作为具有完整业务功能的成品应用。

说明依据本仓库文档与源码整理于 2026-09-23；此次整理未运行应用或活动脚本。
